# Marco de Seguridad y Cumplimiento Normativo (AiAppFactory)
### Proyecto: VetTrack

Este repositorio opera bajo los controles de seguridad y privacidad:
- **SOC 2 Type II:** Trust Services Criteria (Seguridad, Disponibilidad, Integridad, Confidencialidad, Privacidad).
- **ISO/IEC 27001:2022:** Sistema de Gestión de Seguridad de la Información (Anexo A verificado).
- **ISO/IEC 27701:2019:** Sistema de Gestión de Información de Privacidad y PII.
- **Protocolo de Cierre v4:** 50+ tests en 5 capas, 0 vulnerabilidades en Security Guardian y auditoría de Compliance obligatoria.
